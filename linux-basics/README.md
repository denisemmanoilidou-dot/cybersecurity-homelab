# Laboratorio 1: Fundamentos de Linux y Gestión de Permisos

## Descripción
En este primer laboratorio práctico en Ubuntu Linux, se configuró un entorno de trabajo virtualizado para practicar comandos básicos de navegación, gestión de archivos y modificación de permisos de seguridad mediante notación octal.

## Comandos Ejecutados
- `mkdir ciberseguridad`: Creación de la carpeta de trabajo.
- `cd ciberseguridad`: Navegación al directorio del proyecto.
- `nano lab1.txt`: Creación y edición del archivo de notas.
- `cat lab1.txt`: Visualización del contenido en la consola.
- `ls -l lab1.txt`: Inspección de los permisos del archivo.
- `chmod 444 lab1.txt`: Restricción de permisos a modo solo lectura (`r--r--r--`).
